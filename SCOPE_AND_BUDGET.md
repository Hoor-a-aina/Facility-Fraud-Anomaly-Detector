# Scope and budget

## Scope statement
This prototype prioritises unusual facility-management transactions for human review. It uses synthetic timestamped records for maintenance, cleaning, repairs, utilities, and supplies. It is not a real fraud determination system and uses no real company data.

## Budget rule
Maximum spend: **PKR 0**. Use local Python and free/open-source packages. No paid APIs or cloud services.

## Cost log
The `budget/cost_log.csv` file records expected and actual spend. Software and local compute are budgeted at zero. If any expense occurs, update the sheet immediately; do not report zero if that is no longer true.
